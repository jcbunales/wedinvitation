# V34 – Separate Entourage Admin Fields

The Admin → Entourage editor now uses separate fields for:

- Parents of the Groom
- Parents of the Bride
- Primary Sponsors
- Maid of Honor
- Best Men
- Veil
- Cord
- Candle
- Groomsmen
- Bridesmaids
- Ring Bearer
- Coin Bearer
- Bible Bearer
- Flower Girls

For multi-person groups, names can be entered one per line or separated with semicolons. Existing entourage data is mapped into the matching fields when the admin settings page opens.
